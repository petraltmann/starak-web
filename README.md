# Starák – web

Read-only web view of the **Starák** lodge-stay roster, for phones (iOS/Android) and any browser.

- Single static page (`index.html`) — participants, lodge floor-plan, and billing.
- Loads **live data** from the shared Google Sheet via the gviz endpoint (no sign-in);
  falls back to an embedded snapshot when offline.
- Hosted on **GitHub Pages**.

The full source of the companion Android app lives in a separate (private) repository.
